# v0.4.4

- Updates now show up without restarting the launcher. It checks for a new version every 10 minutes while open, and again when you return to the window, instead of only once at startup. A new release will download in the background and offer "Restart to update".
- Failed downloads retry up to 3 times before giving up (not for missing files), and the progress bar no longer overshoots after a retry.
- Minecraft's console output is saved to `logs/launcher-jvm.log` and included when you send logs to an admin, so a crash before the game writes `latest.log` still leaves something to read.
- Launch diagnostics use the project's real Minecraft and Forge versions and the managed Java path instead of hardcoded values.
