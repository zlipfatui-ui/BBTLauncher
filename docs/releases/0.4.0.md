# v0.4.0

- Projects now come from the manifest the admin dashboard publishes. New projects show up without a launcher update, and each one uses its own Forge version.
- The dashboard can lock a project: the card stays visible with the admin's message, but Install/Play are blocked. Hidden projects never reach the launcher. Before the first manifest loads, Northvale stays locked as in earlier versions.
- The hero area shows each project's own title, season label, tagline, description and artwork. SaiNam keeps its existing artwork and text.
- The launcher remembers the selected project. If that project is later locked or removed, it falls back to the first playable one.
- Shaderpacks marked `seed` in the manifest are accepted. They install once and never overwrite a pack the player already has.
- The launcher now sends `X-BBT-Launcher-Version`, so the server can send it the full manifest. Older launchers keep receiving a compatible subset.
- Discord presence shows the running project's name and Forge version.
