# v0.3.7

- Settings now clearly identifies the Game & Modpack Folder. Saving a new folder copies projects (including worlds), Minecraft, Java, and metadata before switching. Original files are retained. Conflicting destination files are never overwritten.
- Restart to update installs silently and requests relaunch. It rejects duplicate clicks and waits until Minecraft and file operations are idle. Launcher windows are destroyed after electron-updater starts the verified installer so renderer close handlers cannot block shutdown.
- Automatic update downloads remain enabled. Installation runs through Restart to update, rather than bypassing its checks during ordinary app exit.
- Install and Repair now display actionable errors instead of silently returning to the same button.
- Reinstalling a deleted project restores resource packs even when old metadata remains, including after an interrupted reinstall.

The production SaiNam manifest has also been corrected separately: the API was serving an older 208-file manifest against newer download payloads, causing SHA-256 failures during Install and Repair. The approved set contains 200 files / 164 mods. Axiom, CMDCam, Forgematica, Essential and Alex's Caves are excluded. Existing launcher versions receive this server correction on their next manifest refresh.

Validation:
- 205 automated tests, TypeScript, and production build passed.
- Downloaded and verified all 200 production files; a second sync downloaded zero files.
- Copied the complete test pack to another folder, verified ready state, damaged one mod, repaired exactly one file, and verified ready state again. Original files remained intact.
- An isolated Windows NSIS installation on drive D: downloaded an update from a local feed, quit, installed, and relaunched version 0.3.7. The local test server did not support multipart ranges, and the updater successfully fell back to a full download.

The reported 0.3.5-to-0.3.6 installer failure cleared after manually running Setup; its precise old-uninstaller failure was not reproduced. The isolated upgrade validates the revised restart flow but cannot guarantee every older installation will recover automatically. If an older version still stalls, close it and run the 0.3.7 Setup directly.
