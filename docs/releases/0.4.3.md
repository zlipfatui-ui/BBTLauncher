# v0.4.3

- Game files can no longer be changed while Minecraft is running. Download, repair, and adding, removing or toggling mods are refused with a clear message instead of failing halfway on files Windows has locked.
- Only one launcher can run at a time. Opening a second copy now brings the first window to the front instead of letting both write to the same game folder.
- A stalled connection no longer freezes the launcher. The manifest check times out after 15 seconds and a download that receives nothing for 30 seconds is abandoned, so you can simply retry.
- Downloads are written straight to disk and verified as they arrive, so large mods no longer sit in memory, the progress bar moves smoothly, and a failed download leaves no leftover temp file.
- External links open only when they are https, and the launcher window can no longer navigate away or spawn new windows.
- Closing the window during a download no longer causes an error.
