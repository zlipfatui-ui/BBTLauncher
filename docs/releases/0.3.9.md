# v0.3.9

- Settings has a new "ส่ง Logs ให้ Admin" button. It sends the current project's latest.log, debug.log, the newest crash report, the newest launch diagnostics and any JVM crash log, plus basic machine info and an optional note. After sending, the player gets a short report code to give the admin.
- The Minecraft access token is sent only as proof of identity: the server confirms the player's UUID with Mojang. Before upload, the token, other token fields and the Windows user name/home path are removed from the logs. The server removes them again as a second layer.
- Shaderpacks listed in the manifest with `seed` sync mode install only on machines that don't already have them. The launcher never overwrites or deletes a shaderpack the player already has. Shaderpacks in `required` mode are still ignored.

Server side (beforebedtime.net/admin): manifest dashboard with immediate publish and rollback, and a Launcher Logs viewer searchable by UUID or player name.
