# v0.4.1

- Manifest updates arrive without restarting the launcher. It checks every 2 minutes while the window is visible, and again when the window regains focus. When the admin publishes from the dashboard, the project list, artwork and Install/Update/Repair button refresh on their own, with a short "มีอัปเดตใหม่จากเซิร์ฟเวอร์" notice.
- An install in progress or a running game is never interrupted. The new state is picked up after it finishes.
- Polling is cheap: the server answers 304 with no body while the manifest is unchanged.
- Fixed: the selected project was reset to SaiNam on every launch.
