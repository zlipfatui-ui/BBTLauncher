# v0.4.2

- No more hitches when the launcher checks your game files. Each file's hash is remembered by size and modification time, so a re-check (after startup, a project switch, or a dashboard publish arriving via auto-reload) only re-reads files that actually changed. Measured on 317 MB: a re-check went from 944 ms to 7 ms.
- Files are hashed in 1 MB chunks instead of being read whole into memory. The longest freeze dropped from about 500 ms to about 30 ms, so the window stays responsive during the first check too.
