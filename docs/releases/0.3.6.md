# v0.3.6

- Fix custom game folders and display/memory settings being reset when switching projects.
- Serialize settings saves and replace settings.json atomically to prevent overlapping saves from corrupting it.
- Windows Setup now lets you choose where to install the launcher.

To change the game data folder, open Settings > App Directory > Browse, select a folder, then click Save. New downloads use that folder. Existing game data is not moved automatically; select its existing launcher data root to reuse it.

The Setup installation folder contains the launcher application. Settings > App Directory controls game data, Java, and Minecraft downloads separately.

Windows Setup supports automatic updates from earlier installed versions. Portable is also available and should be updated manually.

Validation: 195 tests passed; TypeScript and production build passed. Setup, blockmap, and latest.yml are included for the update feed. An installed 0.3.5-to-0.3.6 update has not been exercised on a separate Windows machine.
